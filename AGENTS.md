# Agent instructions

This repository teaches an agent how to make a product launch film in Remotion.

Read `skills/launch-video-craft/SKILL.md` completely, then `reference.md`, before making a film. Read `example.md` in the same directory after the phases. It is one finished film. Copy its decisions. Do not copy its question, its backdrop, or its APIs onto a different product.

The source of truth is `skills/`. There is one skill.
